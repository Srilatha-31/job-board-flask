About Job Board

Job Board is a simple web application developed using Flask, HTML, CSS, JavaScript, Bootstrap, and JSON.

This platform helps job seekers browse available jobs, search by keyword, filter by location and job type, and view detailed job information.

Features

  • Browse available jobs
  • Search jobs
  • Filter by location
  • Filter by job type
  • View detailed job descriptions
  • Responsive user interface

Technology Stack

  • Python
  • Flask
  • HTML5
  • CSS3
  • Bootstrap 5
  • JavaScript
  • JSON
